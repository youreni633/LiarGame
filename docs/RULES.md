# 삼단오목 규칙

## 경기

- 보드는 10×10이다.
- 한 칸에는 최대 3개의 돌이 쌓인다.
- 각 플레이어는 라운드마다 25개의 돌을 가진다.
- 최대 3라운드이며 먼저 2라운드를 이긴 플레이어가 경기에서 승리한다.
- 1라운드 색은 서버가 안전한 난수로 정한다.
- 2라운드부터는 직전 라운드 패자가 색을 선택한다.
- 라운드 무승부는 점수에 반영하지 않고 같은 라운드 번호/색 배정으로 재시작한다.

## 기본 배치

기본 배치 순서는 다음과 같다.

```text
BLACK, WHITE, WHITE, BLACK, BLACK, WHITE
```

- 중앙 4칸 `(4,4)`, `(4,5)`, `(5,4)`, `(5,5)`에는 놓을 수 없다.
- 같은 색이 기본 배치에서 이미 놓은 돌의 8방향 인접 칸에는 놓을 수 없다.
- 상대 색 돌과의 인접은 허용한다.
- 각 슬롯 제한시간은 30초다.
- 기본 배치가 끝나면 흑부터 일반 게임을 시작한다.

## 일반 행동

- 빈 칸에 자신의 새 돌을 놓을 수 있다.
- 자신의 돌이 맨 위에 있는 칸에서 맨 위 돌 하나를 8방향 인접 칸으로 이동할 수 있다.
- 목적지 높이는 최대 3이다.
- 이동 전 목적지 높이는 출발 칸의 이동 전 높이보다 높을 수 없다.
- 모든 승리 판정은 각 칸의 맨 위 돌만 사용한다.

## 승리

1. 맨 위 돌로 이루어진 정확히 5개의 연속 구간.
2. 자신의 색인 3층 맨 위 돌 5개 이상.
3. 자신의 색인 3층 맨 위 돌이 상하좌우로 연결된 컴포넌트 3개 이상.

6개 이상 연속된 구간은 그 구간 자체로 정확한 오목 승리가 아니다. 단, 별도의 정확히 5개 구간이 있으면 승리할 수 있다.

두 색이 동시에 승리 조건을 만족하면 방금 보드를 변경한 플레이어가 승리한다.

## 시간과 종료

- 기본 배치와 일반 턴은 서버 기준 30초다.
- 시간 초과는 승리 조건을 먼저 재평가한 뒤 승자가 없으면 턴만 넘긴다.
- 시간 초과 횟수로 기권패하지 않는다.
- 합법 행동이 없으면 강제 패스한다.
- 양쪽이 연속으로 강제 패스하면 라운드 무승부다.
- 라운드 항복과 경기 기권은 서로 다른 명령이다.
- 연결 끊김은 즉시 기권으로 처리하지 않고 오프라인 상태로 유지한다.
